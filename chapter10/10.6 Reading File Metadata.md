# System-Level I/O

## 10.6 Reading File Metadata
An application can retrieve information about a file (sometimes called the file’s metadata) by calling the stat and fstat functions.
```c
#include <unistd.h>
#include <sys/stat.h>

int stat(const char *filename, struct stat *buf);
int fstat(int fd, struct stat *buf);
```

Returns: 0 if OK,−1 on error

The members of a `stat` structure includes `st_mode`(permission bits and file type) and `st_size`(file size in bytes).
