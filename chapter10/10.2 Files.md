# System-Level I/O
## 10.2 Files
Each Linux file has a *type*:
+ *regular file*: contains arbitrary data
+ *directory*: a file consisting of an array of *links*, where each link maps a *filename* to a file, or another directory. A directory has at least 2 entries, `.` is a link to itself, and `..` is a link to parent directory. 
+ *socket*: used to communicate with another process across a network.
Other types includes named pipes, symbolic links, character and block devices.
