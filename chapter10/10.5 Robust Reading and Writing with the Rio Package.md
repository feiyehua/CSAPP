# System-Level I/O
## 10.5 Robust Reading and Writing with the `Rio` Package
The `Rio` package provides convenient, robust, and efficient I/O in applications such as network programs that are subject to short counts. Rio provides two different kinds of functions:
+ Unbuffered input and output functions
+ Buffered input functions

The Unbuffered input and output functions will restart after `read` or `write` is interrupted by the return from an application signal handler.

The Buffered input functions requires a `struct` as a buffer to reduce the number of system traps.
